international code together. The release preserves these historical files

not supplied, so the repository's MIT grant does not relicense the bot archive.

Snapshot labels describe the available provenance evidence, not a legal
determination of authorship. This release does not claim that all archived
code is solely authored by Jackson Tai, or that every version was the final
First Prize submission. Existing third-party rights and applicable permissions
remain with their respective holders.

The public package excludes raw opponent collections, downloaded CodeCombat
engine bundles, captured sessions, payloads and private account records. No
license from those excluded artifacts is applied to this repository by
implication.
